# 한국어 자막 합성 영상 001

`mp4/`의 GAMEINTRO, GAMEEND, REUNITED, TITLES 4개 파일은 한국어 자막을 영상 픽셀에 직접 합성한 결과다. 플레이어 자막 기능 없이 표시된다. CSV에 대사가 없는 다른 22개 영상은 재인코딩하지 않았다.

- 게임과 같은 KyoboHandwriting2019.ttf, 24px, 흰색 글자.
- 하단 중앙, 바닥 여백 10px. 자막 주위 검정 음영 불투명도 약 71%, 좌우 안쪽 여백 12px.
- 최대 글자 폭 420px, 필요시 두 줄. 이번 59개 문장은 모두 한 줄에 들어갔다.
- 원본 480×272, 30000/1001 fps 및 프레임 수 유지. H.264 CRF 16, yuv420p. 영상은 자막 합성을 위해 재압축했으며 오디오는 기존 AAC 패킷을 그대로 복사했다.
- CSV의 시작/종료 시각 그대로 사용, 약 33.37ms 영상 프레임 단위로 표시. 읽기 시간 연장은 하지 않았다.
- `srt/`: 수정 참고용 파일별 SRT 4개. SRT는 서식/폰트를 포함하지 않는다. MP4 재생 시 이 SRT를 추가로 불러오면 자막이 중복될 수 있다.
- `qa/`: 실제 최종 MP4에서 각 자막 중간 프레임 59장과 모음 이미지 5장.
- `manifest.json`: 입력·출력 해시, 폰트 해시, 행별 표시 프레임 수, 검증 결과.

검증: 모든 출력의 영상/오디오 전체 디코딩 통과. 입력과 출력의 프레임 수 및 오디오 패킷 SHA-256 일치. 폰트의 전체 사용 글자 수록 여부, 시간 순서/비중첩/영상 길이 내 배치, 59개 자막의 실제 표시 프레임 존재 확인. 모음 이미지 5장을 열어 모든 59개 자막의 글자·검은 음영·하단 배치와 잘림 없음을 확인했다.

전편 연속 재생/청취에 의한 음성 동기 검수는 미수행. 기존 CSV needs_review 13행과 ASR 기반 타이밍은 그대로이며 짧은 감탄사는 읽기 시간이 짧을 수 있다. 원본 ISO/PMF/편집 MP4/CSV/폰트/005 빌드는 보존했다. 이 결과는 편집·확인용 MP4이며 PSP 호환 PMF 변환 및 게임 재삽입은 아직 하지 않았다.

재현: 프로젝트 루트에서 `python scripts/burn_movie_subtitles.py --output workspace/video/subtitled_002_kyobo24`. 출력 폴더가 있으면 중단한다. Python 의존성: Pillow, fontTools, imageio-ffmpeg. 번역 수정은 원본 CSV에 반영하고 새 출력 폴더로 재실행한다.

다음 작업: GAMEINTRO.mp4를 재생해 읽기 시간과 음성 동기를 확인한다. 검수 후 PMF 재패키징과 게임 내 재생 가능성을 별도로 검증한다.
