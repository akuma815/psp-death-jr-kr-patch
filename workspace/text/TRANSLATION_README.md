# Death Jr. 영문 스크립트 번역 안내

2026-09-13 갱신: 사용자가 번역을 마쳐 `DeathJr_English_Script_Korean.csv`를 제공했다. **현재 편집/빌드 SSOT는 Korean CSV**이며, 아래 English CSV 설명은 최초 추출 이력이다. 003 빌더가 Korean CSV의 원문/ID/토큰과 번역을 검증한다. 기존 `verify_translation_csv.py`는 최초 English CSV를 검사하므로 이번 번역 빌드 검증과 혼동하지 않는다.

번역 파일: **DeathJr_English_Script.csv** — UTF-8 BOM, 708항목 / 중복을 제외한 원문 597종.

`translation` 열에 한글 번역을 입력하세요. 필요하면 `notes`에 의견을 적으세요. 첫 대사 `What happened?`에는 사용자가 정상 출력을 확인한 `무슨 일이야?`를 넣었습니다.

- `id`, `original`, 원문 위치와 `raw_hex`는 유지하세요. 같은 문구도 실제 저장 위치가 다르면 별도 행입니다.
- `{BYTE_A4}` 같은 토큰은 원본 버튼/확장 문자 바이트입니다. `%d`, `%s` 같은 치환 코드도 유지하세요. `I{BYTE_92}ll`의 92는 문장 내 구두점 후보로, 버튼이라고 단정하지 않습니다. 한국어에서 불필요하면 notes에 제거 의견을 남겨 주세요.
- 원문 한 문장이 여러 행에 나뉘어 있습니다. 한 행씩 번역하며 행을 합치거나 삭제하지 마세요. 파일 순서는 **원본 저장 위치 순서**로, 실제 대화 진행 순서와 다를 수 있습니다.
- `original_bytes`는 원문 바이트 수이지 한글 글자 제한이 아닙니다. `fixed_buffer_bytes=32`는 확인된 UI 문자열 버퍼의 NUL 포함 용량입니다. 전체 한글 인코딩/재배치는 후속 구현 대상이므로 이 수치에 맞춰 번역을 억지로 줄이지 마세요.
- 버튼만 있는 행과 성적 `A`는 원문을 그대로 translation에 복사해도 됩니다. `Costs X Widgets`는 정적 템플릿으로 런타임 가격 문자열과 별도 보존했습니다.
- 저장할 때 **CSV UTF-8** 형식을 선택하세요. Excel에서 인코딩을 묻는 경우 UTF-8을 선택하세요.

## 포함 범위와 남은 범위

복호화 EBOOT의 영문 대사·튜토리얼·NPC 대화·무기명·업그레이드 설명·레벨명·메뉴·치트 알림과, STR 파일에서 확인한 시작 메뉴 3개 및 레벨 문구 2개를 포함했습니다. 중복 원문을 삭제하지 않았습니다.

이는 **확인한 저장 문자열의 통합 추출본**입니다. 전체 게임의 모든 영어 표현을 빠짐없이 추출했다는 판정은 아직 아닙니다. PMF 영상의 음성 대사, 영상/텍스처에 그려진 글자, 아직 구조를 해석하지 못한 데이터는 별도 조사 대상입니다. STR 문구 5개는 화면 사용 경로를 아직 추적하지 않았습니다. 대사 화자·이벤트·장면 순서 역시 아직 연결되지 않았습니다.

`english_script_source.json`은 추출 당시 원문/초기 상태의 고정 스냅샷입니다. 편집할 번역 SSOT는 CSV 하나입니다. 기존 `firstline.json`은 PoC 001 재현용으로 보존하며, 전체 번역의 편집 대상이 아닙니다.

추출 재현: 프로젝트 루트에서 `python scripts/export_english_script.py`. 번역 덮어쓰기를 막기 위해 CSV가 이미 있으면 중단합니다. 재추출은 별도 프로젝트 복사본에서 실행하세요. 검증 기록: `docs/english_script_export_report.json`.
