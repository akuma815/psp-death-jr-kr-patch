## 확인 결과

원문 ID `ELF_001C3DE8`은 무기 획득 메시지의 공통 앞부분이다. ELF 파일 오프셋과 모듈 상대 주소의 차이는 0x80이다. 원문 상대 주소 0x1C3D68을 만드는 LUI/ADDIU 쌍과 이후 복사 명령을 확인했다. 첫 문자열은 객체+0x9D, 아래 무기 이름은 객체+0x109에 들어간다. 두 텍스트 슬롯 간격은 0x6C, 각 복사 상한은 31바이트와 NUL이다. 하나의 완성 문장으로 추출된 항목이 아니라 별도 UI 텍스트 레코드 두 개로 구성된다. 실제 화면의 좌표/줄 배치는 이번에 확인하지 않았다.
